
# 🧠 AI技术底层

### 一、LM（大语言模型）与 Token——AI的“心脏”与“语言翻译官”

#### 1. 大语言模型的工作原理：文字接龙游戏
- 模型每次只预测**下一个最可能的词**，然后把这个词加回输入，继续预测，直到输出结束符号。
- 这就是为什么AI回答时是**一个字一个字蹦出来**的。

> 🧩 比喻：就像你说“我喜欢吃”，AI接“苹果”，然后“我喜欢吃苹果”，再接“。”结束。

#### 2. Token：AI看懂文字的关键
- **Tokenizer** 负责两件事：
  - 编码：把文字切分成小块（token），并转成数字ID
  - 解码：把数字ID转回文字
- Token ≠ 单词，它是模型自己学会的切分方式。

> 📏 换算参考：
> - 1 token ≈ 0.75 个英文单词
> - 1 token ≈ 1.5~2 个汉字

> 🧩 比喻：Tokenizer 就像翻译官，把人类的“你好”翻译成模型能懂的“102, 450”。

### 二、Context 与 RAG——AI的“临时工作台”与“图书管理员”

#### 1. Context：模型的短期记忆
- 每次发消息时，程序会把**对话历史 + 系统提示 + 用户问题 + 工具列表**一起打包发给模型。
- 这就是为什么AI能“记住”之前的对话。

> 🧩 比喻：Context 就像模型的临时工作台，每次干活前把所有资料摊开。

#### 2. Context Window：工作台的大小
- 代表模型一次能处理的最大 token 数量。
- 比如 GPT-4 的窗口是 105 万 token。

> ⚠️ 问题：窗口再大也有限，塞太多内容会“撑爆”。

#### 3. RAG（检索增强生成）：聪明的图书管理员
- 不把整本书给模型，而是只取出**最相关的几个片段**。
- 既节省成本，又突破窗口限制。

> 🧩 比喻：你去图书馆问“秋天的诗”，管理员不会把整本书给你，只给你几页相关的。

---

### 三、Prompt——给AI的“指令卡”

#### 1. Prompt 的类型
| 类型 | 谁写的 | 作用 |
|------|--------|------|
| User Prompt | 用户 | 提出具体任务或问题 |
| System Prompt | 开发者 | 设定人设、规则、风格 |

> 🧩 比喻：System Prompt 是AI的“上岗前培训”，User Prompt 是“具体任务指令”。

#### 2. Prompt Engineering 核心
- 把话说清楚，减少AI的猜测空间。
- 示例：
  - ❌ 模糊：“写一首诗”
  - ✅ 精准：“写一首五言绝句，秋天落叶，悲凉风格”

---

### 四、Tool 与 MCP——给AI“装上手和脚”

#### 1. Tool（工具）：让AI感知外部世界
- 本质是一个**函数**，比如查天气、定位、搜地图。
- 模型不会自己调用工具，它只是**决定要调用**，并输出指令。

> 🧩 比喻：模型是“动嘴”的指挥官，平台是“动手”的执行者。

#### 2. 调用流程
1. 用户问：“今天天气怎么样？”
2. 模型决定调用“查天气”工具
3. 平台执行调用，拿到数据
4. 模型把数据翻译成自然语言

#### 3. MCP（模型上下文协议）：AI界的Type-C接口
- 统一工具调用标准，一次开发，多平台使用。
- 解决不同平台（OpenAI、Anthropic、Google）接口不统一的问题。

> 🧩 比喻：MCP 就像统一的插头标准，不用再为不同设备准备不同的充电器。

---

### 五、Agent 与 Skill——AI的“大脑”与“行为说明书”

#### 1. Agent（智能体）：能自主拆解任务
- 具备**思考、规划、执行、观察**的循环能力。
- 示例任务：“查天气，如果不下雨就找附近公园”

> 🧩 比喻：Agent 像一个真正的助手，不是回答一个问题，而是主动完成一个任务。

#### 2. Agent 的任务拆解过程
1. 获取当前位置（定位工具）
2. 查天气（天气工具）
3. 判断是否下雨
4. 找附近公园（地图工具）
5. 综合信息给出答案

#### 3. Agent Skill：行为说明书
- 一份本地的 Markdown 文档，定义：
  - 身份（如出门助手）
  - 执行步骤（先查天气，再判断带什么）
  - 输出格式（总结 + 清单）

> 🧩 比喻：Skill 是Agent的“员工手册”，告诉它怎么干活、怎么说话。

- Context 是模型的临时记忆
- RAG 让AI能查百科全书
- Prompt 是控制AI行为的指令
- Tool 让AI感知外部世界
- MCP 统一工具调用标准
- Agent 能自主拆解任务
- Skill 是Agent的行为说明书

> **Token是砖块，Context是工作台，RAG是图书管理员，Prompt是指令卡，Tool是手脚，MCP是统一插头，Agent是大脑，Skill是说明书。**
